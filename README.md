# yt-mini-PIP

A Chrome extension that pops a playing YouTube video into a small floating window (picture-in-picture) when you switch tabs or apps, and puts it back when you return.

**⬇️ Download and setup guide: [mogdhopaul.com/yt-mini-pip](https://mogdhopaul.com/yt-mini-pip/)**

> This extension is no longer updated. [ytModify](https://mogdhopaul.com/ytmodify/) does the same pop-out and more.
